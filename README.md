**ATOM BUILDER**

Julius Aguilar, Ryan Liang, Tho Nguyen 
-----------------------------
Editing any of the values on the left will allow you to search for an atom with matching features. Additional, non-searchable info can be found on the right side of the screen. The buttons / fields at the bottom of the screen allow you to add or remove subatomic particles to create isotopes or alternatively charged atoms. 

Note: Electron configuration exceptions which do not follow the Aufbau principle will be innaccurate.
